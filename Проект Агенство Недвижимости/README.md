Аналитика рынка недвижимости СПб и Ленобласти: сегментация по ликвидности и сезонность + дашборд в DataLens
Ссылка на дашборд: https://datalens.yandex/n7z3hnw3ajmq7

Проделанная работа:
Провела EDA и проверку качества данных по объявлениям о продаже жилья. На SQL сегментировала объявления по времени экспозиции и проанализировала сезонность публикаций и продаж за 2015–2018 годы, сравнила показатели по СПб и Ленобласти. Доработала дашборд в DataLens: добавила фильтры, метрики и чарты, реализовала детализацию по периодам через параметры, заменила визуализации на более корректные, добавила признаки инфраструктуры.

Результат:
Определены ликвидные сегменты и сезонные пики на рынке недвижимости; выявлены региональные различия по стоимости и скорости продажи. Подготовлен интерактивный дашборд для поддержки решений агентства по выходу на новый рынок.

Инструменты и навыки:
PostgreSQL, DBeaver, SQL (агрегации, категоризация, даты, статистики), Yandex DataLens (параметры, фильтры, чарты, UX дашборда), сегментация и сезонный анализ, проверка качества данных, формулирование бизнес рекомендаций.
