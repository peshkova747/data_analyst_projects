# Дашборд и аналитика ключевых метрик доставки еды в Саранске (май — июнь 2021)

## Проделанная работа:
- Подготовила SQL запросы (PostgreSQL) для агрегации данных и построения витрин
- Рассчитала метрики (DAU, Conversion Rate, средний чек, LTV, Retention) на QL в DataLens.
- Построила визуализации, собрала дашборд, проанализировала тренды и аномалии, подготовила аналитическую записку с выводами и рекомендациями для старшего аналитика.

## Результат:
- Создан готовый дашборд с корректными метриками и наглядными графиками.
- Выявлены ключевые тренды: динамика активности и конверсии, поведение среднего чека, различия в удержании когорт, вклад топ ресторанов и блюд в доход.
- Подготовлены практические выводы для бизнеса. Ссылка: https://datalens.yandex/nrhegvj125le7?tab=Pd

## Инструменты и навыки:
PostgreSQL, SQL, Yandex DataLens, QL; продуктовые метрики (DAU, CR, LTV, Retention, средний чек), когортный анализ, сегментация, визуализация данных, выявление аномалий, подготовка отчётов и рекомендаций.
