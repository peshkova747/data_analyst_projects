# Анализ поведения пользователей и проверка гипотез для сервиса проката самокатов GoFast

## Проделанная работа:
- Загрузила и предобработала три датасета, объединила данные пользователей, поездок и тарифов.
- Провела EDA, визуализировала распределения и различия между подписчиками и free пользователями.
- Рассчитала выручку по пользователям и месяцам/
- Проверила три бизнес гипотезы (длительность поездок, расстояние, выручка).
- Построила вероятностную модель на основе нормального распределения: оценила вероятности длительных поездок, долю поездок 20–30 мин и 90 й процентиль для установки лимита.

## Результат:
- Подготовлена аналитическая витрина с агрегированными метриками и выручкой.
- Подтверждены/опровергнуты ключевые гипотезы о подписчиках.
- Рассчитаны метрики для промоакций и лимитов, снижающих износ техники.
- Сформированы практические рекомендации для продуктовой команды.

## Инструменты и навыки:
- Jupyter Notebook, Python (Pandas, Matplotlib, Seaborn, Scipy, NumPy)
- предобработка данных, EDA
- агрегации и расчёт выручки
- проверка гипотез
- вероятностное моделирование
- визуализация
- формулирование бизнес рекомендаций.
