# Анализ платёжного поведения и внутриигровых покупок в  игре «Секреты Темнолесья»

## Проделанная работа:
- Провела EDA схемы БД.
- Проверила данные на пропуски и аномалии.
- Рассчитала долю платящих игроков и зависимость от расы, статистику покупок (сумма, среднее, медиана), популярность эпических предметов.
- Решила ad hoc задачу по сегментации активности игроков по расам.
- Подготовила выводы и рекомендации для команды.

## Результат:
- Получены ключевые метрики монетизации (доля платящих, средние траты, популярность предметов)/
- Проверена гипотеза о влиянии расы на активность покупок.
- Подготовлен набор запросов и аналитических выводов для поддержки продуктовых решений.

## Инструменты и навыки:
PostgreSQL, DBeaver, SQL (JOIN, агрегации, статистика, сегментация), разведочный анализ данных, валидация пропусков, формулирование бизнес выводов и рекомендаций, работа с гипотезами и ad hoc запросами.
