# Аналитика «Яндекс Афиши»: дашборд и проверка гипотез о поведении пользователей

## Ссылка на дашборд: https://datalens.yandex/q56gvb0it0rca?tab=vp

## Проделанная работа:
- Рассчитала ключевые метрики в SQL (выручка, заказы, средний чек в разрезе устройств, событий, регионов)/
- Построила дашборд в Yandex DataLens с фильтрами и динамикой.
- В Python провела предобработку данных (приведение к единой валюте, создание признаков, обработка аномалий), исследовала сезонность и недельную цикличность.
- Проверила гипотезы о различиях мобильных и десктопных пользователей с помощью U теста Манна Уитни.

## Результат:
- Выявлен рост заказов в 3 раза с июня по октябрь, сезонные сдвиги в предпочтениях (стендап и «другое» растут, концерты и театры — снижаются). 
- Подтверждено: мобильные пользователи чаще делают заказы, но реже возвращаются (p value < 0,05).
- Дашборд может быть использован продуктовой командой/
- Gодготовлены рекомендации по промо, ценовой политике и удержанию пользователей.

## Инструменты
SQL, Yandex DataLens, Python (Pandas, NumPay, ), Jupyter Notebook, U тест Манна Уитни.
